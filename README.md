# SLZ_Vowels

This repository contains the code and manuscript for an analysis of the vowel overlap between [u] and [o] in Santiago Laxopa Zapotec. 

## Scripts for analysis

All code for this analysis is found in the folder `scripts`. The individual scripts are prefixed with a three digit number indicating the order that the scripts need to be ran in. 

Additionally, this repository comes with a online Docker profile through [MyBinder](https://www.mybinder.org/). In order to open this repository in the online Docker profile with an instance of RStudio Server running please click the `Launch Binder` button below. 

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/mylbrinkerhoff/SLZ_vowels/main?urlpath=%2Frstudio)

## Manuscript

The manuscript associated with this analysis was composed in [Quarto](https://www.quarto.org). The manuscript and all associated files are located in the `output/reports` folder.
